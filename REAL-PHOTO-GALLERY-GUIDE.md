# Real Tesla photo gallery — Version 5

Upload the entire contents of this folder into the root of your existing GitHub repository. Keep your existing config.js unchanged. No database changes are required.

New files: `real-gallery.js`, `real-gallery.css`. Updated files: `catalogue.js`, `giveaway.js`, `catalogue.html`, `vehicle.html`, `giveaway.html`.

Each Tesla model page loads up to 18 real Wikimedia Commons photographs, showing thumbnails, a large image, photo category filters and photographer/source/licence credits. The catalogue and giveaway cards also load real photographs.

Important: Wikimedia Commons is a third-party service. The gallery uses the Commons API at runtime and requires an internet connection. Images may be temporarily unavailable or returned search results may depict a different model year; review each photo before public promotion. Creative Commons images may require attribution and share-alike compliance. Do not remove credits. For a production site, manually curate and host appropriately licensed images instead of relying on live search.

This remains an independent Tesla showcase and giveaway DEMO. No real payments or prizes.

Installation: Extract ZIP → GitHub repo → Add file → Upload files → upload files to repository root → Commit → wait for Vercel Ready → visit /vehicle.html?id=model-3 and /giveaway.html.
